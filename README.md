# Telegram & Discord Боты: Полный курс (Задания 1-10)

Этот репозиторий содержит решения всех 10 заданий по разработке ботов с использованием ИИ.

## Список реализованных заданий:

*   **Задание 1:** Эхо-бот с базовыми командами (`/start`, `/help`).
*   **Задание 2:** Интерактивные клавиатуры (Reply и Inline).
*   **Задание 3:** Интеграция с API (погода OpenWeatherMap и валюты ExchangeRate-API) с кэшированием.
*   **Задание 4:** Бот-опросник с управлением состоянием (FSM).
*   **Задание 5:** Бот с постоянным хранением данных в SQLite (`/stats`, `/profile`, `/users`).
*   **Задание 6:** Discord-бот со слеш-командами и модерацией (файл `discord_bot.py`).
*   **Задание 7:** Умный чат-бот с интеграцией GigaChat (LLM) и контекстным диалогом.
*   **Задание 8:** RAG-бот для ответов по документации (файл `docs.txt`).
*   **Задание 9:** Агентный бот с вызовом внешних инструментов (погода, время, калькулятор).
*   **Задание 10:** Бот с анализом тональности и генерацией изображений (через Pollinations AI) с кэшированием.

## Как запустить:
1. Установить Python.
2. Создать виртуальное окружение: `python -m venv venv`
3. Активировать: `venv\Scripts\activate`
4. Установить зависимости: `pip install -r requirements.txt`
5. Вставить свои ключи (Telegram, GigaChat) в файл `bot.py`.
6. Запустить: `python bot.py` (для Telegram) или `python discord_bot.py` (для Discord).
